# 文件工作區與編輯功能

## 文件匯入與下載

Studio 可匯入 `.md`、`.markdown`、`.mdown`、`.mkd` 與 `.txt`，下載時統一輸出 UTF-8 `.md`。`Ctrl/Cmd + S` 可直接下載目前文件。

## 多文件工作區

同一個瀏覽器工作區可以管理多份文件，並支援：

- 新增、複製及刪除文件。
- 切換編輯、並排與預覽模式。
- 拖曳或使用鍵盤調整編輯與預覽欄寬。
- 匯出及匯入完整工作區 JSON。

這裡的多文件功能適合日常編輯；正式的單頁發布順序由 [`guide-order.txt`](04_publish.md#固定文件順序) 管理，不以瀏覽器中的排列為準。

## 快照與版本比較

每份文件最多保留 20 份本機快照，支援：

- 自訂快照名稱與最多五個標籤。
- 搜尋、重新命名、刪除及單獨下載。
- 最多釘選五份重要快照。
- 與目前內容並排比較新增及移除行。
- 還原前自動建立安全備份。

## 搜尋與雙向定位

- `Ctrl/Cmd + F` 開啟搜尋與取代。
- 支援上一筆、下一筆、區分大小寫、逐筆取代及全部取代。
- 編輯區游標可定位預覽段落。
- 點選預覽中的標題、段落、表格或圖形，可回到來源行。

## 文件健檢

Studio 會檢查文件結構、標題、圖片替代文字及 Mermaid 語法。規則修正會先顯示前後比較，由使用者選擇是否套用，並建立可還原快照。
